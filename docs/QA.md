# Проверка Jarvis Desk — 20 октября 2026

## Публикация

- Публичный репозиторий: [TamerlanTA/jarvis-desk](https://github.com/TamerlanTA/jarvis-desk), основная ветка `main`.
- Работающее приложение: [GitHub Pages](https://tamerlanta.github.io/jarvis-desk/).
- Pages собирается из `gh-pages`, корень `/`, HTTPS включён; проверен статус GitHub Pages `built` без ошибки.
- Публикация выполнена через `npm run deploy`; `predeploy` запускает production build.

- `npm run build` — успешно после каждого этапа реализации.
- `npm run lint` — без ошибок и предупреждений.
- `npm test` — 12 тестов, все проходят.
- `npm audit` — 0 известных уязвимостей на момент установки зафиксированных зависимостей.

## Браузерная проверка

Использован встроенный браузер Codex (IAB), без Playwright-fallback. Проверены localhost и опубликованный URL. В production не обнаружены сообщения `warn` или `error` в консоли.

На публичном сайте выполнены:

1. Отправка пустого названия → сообщение валидации; корректное создание задачи.
2. Обновление страницы → добавленная задача сохранилась.
3. Редактирование названия и даты; нативный ввод даты с клавиатуры → новая дата отображается в списке.
4. Очистка даты с клавиатуры → ошибка, форма не сохраняется; отмена оставляет старую задачу.
5. Отметка выполнения → обновление счётчиков и процента.
6. Совместные направление + статус + поиск → нужная задача; неизвестный запрос → пустой результат; сброс возвращает весь список.
7. Отмена удаления сохраняет задачу; подтверждение удаляет её. Временная тестовая задача удалена после проверки.
8. Таймер: 5 минут → старт → наблюдаемый отсчёт → пауза → сброс; переключение на 15 и 25 минут.
9. Обновление погоды → loading → реальный ответ API, единицы км/ч и источник отображаются.
10. Мобильная форма открывается, помещается в экран и закрывается; Escape проверен на desktop.

HTTP-ошибки, таймауты, повреждение хранилища и полное завершение таймера проверены детерминированными автотестами; production API во время проверки отвечал успешно.

## Адаптивность

Проверены ширины 320, 390, 768, 1280 и 1505 CSS px. Горизонтального переполнения нет. На небольших экранах поиск и select располагаются друг под другом, метаданные переносятся, панели таймера и погоды переходят под задачи. Мобильный диалог не имеет внутреннего горизонтального переполнения.

- [Desktop](desktop.png): скриншот production-версии, получен через `tab.screenshot({ fullPage: true })` в IAB при viewport 1505 × 1045. Полоса прокрутки может уменьшать ширину самого PNG на 15 px.
- [Mobile](mobile.png): production-версия при viewport 390 × 844.

## Границы реализации

Задачи сохраняются локально для конкретного браузера и origin. Таймер и фильтры после обновления страницы сбрасываются. Погода зависит от сети и доступности Open-Meteo; ошибки имеют отдельный UI с повтором запроса. Backend, авторизация и роутер для данного объёма не нужны.
